# **App Name**: eBird Spotter

## Core Features:

- Hotspot Search: Search for birding hotspots using eBird API with hotspot ID.
- Observation Fetch: Fetch the past 7 days of bird observations from the eBird API for the selected hotspot.
- Frequency Calculation: Calculate and display species frequency based on observation data. Uses tool to incorporate checklist information.
- Common Bird Filter: Toggle to filter out common species (e.g., House Sparrow) from the results.

## Style Guidelines:

- Primary color: Soft green (#A7D1AB) to evoke nature and tranquility.
- Background color: Very light gray (#F5F5F5), near-white, for a clean and modern look.
- Accent color: Earthy brown (#A0785A), analogous to the primary green, but less saturated and darker, for highlights and key actions.
- Body and headline font: 'PT Sans' for a modern look and some warmth and personality.
- Use bird-related icons to represent species or categories of information.
- Clean and spacious layout with clear sections for search, results, and filters.
- Subtle transitions for data loading and filtering to improve UX.
